## 📝 Customization Guide

To customize this portfolio with your own information:

1. **Update Social Links**: Edit the URLs in `index.html` for GitHub, LinkedIn, Twitter, and email
2. **Modify Projects**: Add your actual projects with real GitHub repository links and live demo URLs
3. **Update Skills**: Adjust the skills listed in the Skills section to match your expertise
4. **Edit Experience**: Update the Experience section with your actual work history
5. **Customize Content**: Replace placeholder text with your personal information and achievements
